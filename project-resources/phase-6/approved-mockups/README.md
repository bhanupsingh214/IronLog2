- Workout is not a bottom-navigation destination.
- History is not a bottom-navigation destination; access it from Dashboard / Recent History.
- Add Log follows the Start Workout visual language while retaining its historical logging workflow.
- Existing deterministic feature logic remains the source for Progress and Goals intelligence; the UI mockups do not require LLM-generated analysis.
